Links (separate from Omni-tool)

Optional named links in base.links: each entry is key: url — key is the label in the notification, url is the href. Empty values are omitted.

Built-in keys: report, dashboard, testops, build.

{
  "links": {
    "report": "${ALLURE_REPORT_URL}",
    "dashboard": "${ALLURE_DASHBOARD_URL}",
    "testops": "https://allure.qa.guru/project/…",
    "build": "${BUILD_URL}"
  }
}
